# Local Dev Servers & Links

Run `scripts\dev-up.ps1` (PowerShell) to start everything below in one shot. It opens
two new PowerShell windows (API, web) and starts the Postgres, Qdrant and Redis Docker
containers, launching Docker Desktop first if it isn't already running.

Everything runs on this machine. There are no hosted services in the data path.

## App

| Service | URL | Notes |
|---|---|---|
| Frontend (Next.js) | http://localhost:3000 | `npm run dev` in `apps/web` |
| Backend API (FastAPI) | http://localhost:8000 | `uv run uvicorn services.api.main:app --port 8000` from repo root |
| API interactive docs (Swagger) | http://localhost:8000/docs | Auto-generated by FastAPI |
| API health check | http://localhost:8000/health | Returns `{"status": "ok"}` |

> The API is **not** started with `--reload`. Restart it after backend edits or you
> will be testing stale code.

## Candidate Intelligence routes (Module 01)

All under the API base URL, require a candidate's bearer token (JWT issued by `POST /auth/login`):

| Route | Purpose |
|---|---|
| `GET /candidates/me` | Merged candidate profile |
| `GET /candidates/github/oauth-url` | Start GitHub OAuth connect |
| `GET /candidates/github/oauth/callback` | GitHub OAuth token exchange (hit via the frontend's `/api/auth/github/callback` passthrough) |
| `POST /candidates/me/ingest/resume` | Upload + parse resume |
| `POST /candidates/me/ingest/certificate` | Upload + OCR a certificate |
| `GET /candidates/me/score` | Latest Talent Score + sub-score breakdown |
| `GET /candidates/me/score/history` | Score history (trend line) |
| `GET /candidates/me/dashboard` | Aggregated dashboard payload |

## Infrastructure

All three come up together with
`docker compose -f infra/docker-compose.yml up -d`.

| Service | URL / Location | Notes |
|---|---|---|
| Postgres | `localhost:5432` | Container `trace_postgres`, database `talent_platform`. Schema via `alembic upgrade head` |
| Qdrant | `localhost:6333` | Container `trace_qdrant`. Dashboard at http://localhost:6333/dashboard |
| Redis | `localhost:6379` | Container `trace_redis`. Backs the job queue |

## External integrations (status as of this build)

These are the only network calls the app makes, and all are outbound API calls —
none of them store application state.

| Integration | Configured? | Used for |
|---|---|---|
| Auth (self-hosted JWT) | ✅ `JWT_SECRET_KEY` in `.env` | Sign-in/sign-up, bcrypt hashing, HS256 token verification |
| GitHub OAuth | ✅ real keys in `.env` | `FR-1.1` GitHub profile ingestion |
| Anthropic (`ANTHROPIC_API_KEY`) | ✅ real key in `.env` | Resume structured extraction, Project Quality/Innovation sub-scores, certificate OCR vision fallback, interview topic generation and turn evaluation |
| Cloudinary (`CLOUDINARY_URL` etc.) | ✅ real credentials in `.env` | Resume/certificate file uploads |
| Langfuse | ❌ empty | Agent run tracing — optional, not required to run the app |
| Sentry | ❌ empty | Error reporting — optional |

Fill these into `.env` (not `.env.example`).

## Stopping everything

```
docker compose -f infra/docker-compose.yml stop
```
Close the two PowerShell windows opened by `dev-up.ps1` (or Ctrl+C in each) to stop
the API and web servers.
